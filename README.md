A raytracer developed for my Third Year Project, capable of rendering multiple scenes of simple primitives with global illumination, diffuse, matte and transparent materials. 
The implementation is software-based and does not leverage the GPU and is rendered entirely with the CPU (single-threaded). 

To compile and build the project, use the included Makefile.

To render an image, redirect the output to PPM by using ./main > image.ppm and select scene parameters from the GUI.
